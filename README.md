# StrumFour

Four-bar live acoustic-strum desk for bedroom producers and AI-music finishers.

The loop is programmed. Nobody is sitting in the guitar chair. StrumFour writes four live nylon bars between the pocket and the hook so the song has wood in it.

Live chairs only: FluidR3 nylon, piano, upright, kit (samples hosted with PreEight).

Distinct from BreathFour (section air), TagFour, AmenFour, LiftTwo, PreEight, AfterHook, EndEight, LastHook, LeadFour, GlockFour, DropFour.

Shipped 2026-10-01 after X conversations about unfinished DAW files and the recurring note that unfinished songs usually need acoustic guitar.

## Form

1–4 pocket · 5–8 strum chair · 9–12 hook with guitar locked in

## Play

- A · Pocket loop
- B · Full form
- 8 · Strum + hook only
